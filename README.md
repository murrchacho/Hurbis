# Идея проекта
Сервис представляет собой платформу для IT-рекрутинга. Планируются гибкие фильтры, чаты, видеозвонки и немного магии. 

# Архитектура проекта
Будучи построенным на микросервисах, планируется общение последних через RabbitMQ. MVP - на REST.
* Auth - микросервис авторизации и аутентификации получает запросы на регистрацию, вход в систему и проверку JWT-токенов. Генерирует JWT-токены и отдает их в HTTP-Only куках. Хранит необходимую информацию в PostgreSQL.
* CVs CRUD - микросервис CRUD операций с контентом, взаимодействует с MongoDB, где хранится основной контент (резюме пользователей).
* Vacancies CRUD - микросервис CRUD операций с контентом, взаимодействует с MongoDB, где хранится основной контент (объявления компаний).
* Chat - микросервис чата.
* Calls - микросервис видеозвонков.
* Notifications - микросервис рассылки различных уведомлений.
* ...
